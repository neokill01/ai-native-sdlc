## 问题 / Problem

每次开市前，我要手工从一堆渠道汇总信息：各大指数隔夜/盘前表现、重要新闻与情绪、经济日历上今日的高影响事件、以及我自选股的异动。这几个来源散、格式杂、容易漏——信息还没拼完整，九点半就到了。拼出来的"今日要点"往往是凭感觉、不够可复现，也难回头看。

## 期望结果 / Proposed outcome

一条命令，开市前把**最新市场信息**抓齐、合并、分析，输出一份**开市简报**：

- 大盘风向（risk-on / risk-off / neutral，由隔夜指数涨跌与情绪加权判断）
- 显著异动（涨幅/跌幅超阈值的指数）
- 今日高影响事件（经济日历里 impact=high 的条目）
- 重点新闻（按情绪/影响排序的前几条）
- 自选股提示（若有，基于涨跌幅阈值）

简报要**确定性、可复现**（同一数据输入产出同一结果），并能**离线**用样例数据跑通（示例不依赖真实行情/API 密钥）。

## 受影响用户与系统 / Affected users & systems

- 用户：我这个炒股专家（单用户，无鉴权/多租户）。
- 系统：一个 CLI 工具模块；数据来源通过统一 `Source` 接口抽象，可插拔（示例附**内置样例源**，另预留接真实源的扩展点）。

## 约束 / Constraints

- **纯 Python 标准库**，无第三方依赖，`python3` 直接可跑（适合 git 展示、评审者可一键运行）。
- 数据源可插拔：`Source` 接口 + 样例实现；不硬编码某家行情 API，不要求凭据，避免示例跑不起来。
- 幂等、确定性：不写库、无副作用；同一输入→同一输出。
- 简报人类可读、Markdown 输出。

## 成功标准 / Success

1. `python3 -m premarket_brief` 输出一份完整开市简报（含上述五块）。
2. 摘要/分析逻辑有单元测试覆盖（风向判断、异动阈值、高影响事件过滤、多源合并去重）。
3. 示例含样例数据源，离线可跑；`tests/` 全绿。
