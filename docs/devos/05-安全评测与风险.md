# Agentic DevOS · 安全、评测与风险管理 v1.0
状态：设计要求

## 1. 威胁模型
- Prompt Injection：仓库 README、issue、依赖文档可能包含恶意指令；外部内容均作为不可信数据。
- 工具越权：路径穿越、符号链接逃逸、危险 Shell 命令、网络外传。
- 密钥泄漏：环境变量、.env、日志、Diff、工具返回。
- 知识污染：未经验证的模型总结被写入长期记忆。
- 自我批准：编码 Agent 审批自己的 PR 或生产部署。
- 供应链风险：执行不可信依赖安装脚本。
- 资源耗尽：无限循环、昂贵调用、过量并发。

## 2. 防护策略
- 工具网关在模型之外强制鉴权与审批；Prompt/Skill 不是安全边界。
- 沙箱限制工作目录、系统调用、网络、CPU、内存与执行时间。
- 默认只读；写入代码须经 plan 门禁；删除、推送、发布须升级审批。
- 按项目隔离凭据；密钥只在必要工具侧注入，不传给模型上下文。
- 审计日志记录授权主体、工具、资源、结果；存储前脱敏。
- 独立审查与分支保护；Agent 不得合并自己的改动。
- 记忆写入先候选、后审核，保存证据与过期时间。

## 3. 评测体系
| 维度 | 指标 | 证据 |
|---|---|---|
| 任务效果 | 任务成功率、首次通过率 | 预设验收用例、测试报告 |
| 代码质量 | lint/typecheck/test、回归数 | 命令退出码、CI |
| 自主程度 | 人工干预次数、平均修复轮数 | 事件日志 |
| 安全 | 越权拦截率、敏感信息泄漏事件 | 策略测试、审计日志 |
| 效率 | 任务耗时、单位成功任务成本 | trace + 费用 |
| 知识 | 检索命中率、知识冲突率 | 标注评测集 |

## 4. 最小评测集
先收集 10–20 个小型真实任务，覆盖新增 UI、复用组件、API 改造、类型错误修复、测试失败修复、受保护路径、恶意文档指令、超时恢复。每项固定仓库版本、输入、期望变更、验证脚本。

## 5. 风险台账
| 风险 | 级别 | 应对 |
|---|---|---|
| GitHub 写权限不足 | 高 | 文档先离线交付；授权后独立分支实施 |
| 原有 Hooks 与新 Runtime 不兼容 | 高 | 写适配层与策略一致性测试 |
| Coding Harness 绑定供应商 | 中 | 定义 Adapter 与能力探测 |
| 自托管 Runner 不可用 | 中 | CI 迁移评估，禁止假报通过 |
| 项目知识过时 | 中 | 来源版本、索引更新、冲突审查 |
| 自动修复循环失控 | 高 | 时间/费用/轮次三重上限 |
