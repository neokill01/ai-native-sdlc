# Agentic DevOS · 核心流程与接口契约 v1.0
状态：接口设计草案

## 1. 任务状态机
```text
created -> clarifying -> intent_review -> spec_review -> plan_review
-> queued -> preparing -> running -> verifying -> reviewing -> completed
                                |           |
                                |           +--> repairing -> running
                                +--> waiting_approval
任意运行态 -> cancelling -> cancelled
任意运行态 -> failed
可恢复状态 -> paused -> queued
```
所有转移需要校验当前状态、操作者和版本号；禁止跨越审批门禁。状态更新与事件记录应在同一事务内完成。

## 2. 核心实体
- Project(id, repo, defaultBranch, commands, policyVersion)
- Task(id, projectId, goal, acceptanceCriteria, status, createdBy)
- TaskRun(id, taskId, attempt, status, budget, checkpoint)
- Artifact(id, taskId, kind, path, revision, approvalStatus)
- AgentStep(id, runId, kind, inputRef, outputRef, status)
- ToolExecution(id, runId, tool, argumentsHash, resultRef, approvalId)
- Approval(id, taskId, action, scope, status, decidedBy, decidedAt)
- EvalResult(id, runId, checkId, verdict, evidenceRef)
- MemoryCandidate(id, sourceRunId, content, evidenceRefs, status)
- AuditEvent(id, actor, action, resource, timestamp, traceId)

## 4. 任务创建示例
```json
{
  "projectId": "proj_demo",
  "goal": "在用户列表增加手机号搜索",
  "acceptanceCriteria": [
    "复用现有输入组件和请求封装",
    "类型检查与单测通过",
    "不改变既有列表默认行为"
  ],
  "constraints": {
    "maxRepairIterations": 5,
    "timeoutSeconds": 900,
    "maxCostUsd": 3
  }
}
```

## 5. 事件协议
事件类型：task.created、artifact.generated、approval.requested、approval.decided、run.started、tool.requested、tool.completed、verification.completed、run.paused、run.failed、run.completed。
事件包含 eventId、runId、sequence、occurredAt、traceId、payload；支持按 sequence 重放和断线续传。

## 6. 工具契约
每个工具必须声明 name、inputSchema、sideEffectLevel(read/write/destructive)、requiredPermissions、timeout、approvalPolicy。
执行顺序：输入验证→权限/路径检查→必要审批→沙箱执行→脱敏→审计事件→结果返回。

## 7. 验证报告
逐条 acceptanceCriteria 标注 passed/failed/not_run/needs_human_review；附命令、退出码、测试报告路径、Git diff 摘要和环境信息。模型总结不改变实际 verdict。

## 8. 错误与恢复
错误分 transient、policy_denied、validation_failed、tool_failed、budget_exceeded、cancelled、irrecoverable。仅 transient 默认指数退避；写入操作重试前必须校验幂等结果。
