# Agentic DevOS · 文档导航与现状审计
版本：v1.0（设计基线）｜日期：2026-10-30｜状态：待评审

## 1. 定位
在现有 `neokill01/ai-native-sdlc` 基础上，从“AI-Native SDLC 方法论与模板”演进为“可执行、可观测、可验证、可恢复的自主研发平台”。不推倒现有规范，新增 Agent Runtime。

## 2. 本轮已核查来源
- `README.md`：六阶段提交产物链、目录概览、成熟度声明。
- `docs/playbook.md`：六阶段方法论、人工门禁、工具映射。
- `docs/adoption.md`：0–4 成熟度台阶。
- `docs/dsh-preset.md`：DSH preset 说明；实际本机安装状态未验证。
- `artifacts/{intent,spec,plan,review}.md.template`：阶段产物模板。
- `agents/README.md`：Skills 与 Hooks 约定。
- `evals/README.md`：评测 JSON 契约与脚本使用说明。
- `infra/bands.yaml`：运维控制带样例。
- `.github/workflows/agent-evals.yml`：评测 CI 定义。

## 3. 现状与证据边界
| 领域 | 已有资产（根据已读文件） | 缺口或待核实 |
|---|---|---|
| 研发流程 | intent→spec→plan→code/test→PR→incident | 机器可执行的任务状态机 |
| 知识 | Markdown 模板、Skills | 项目上下文检索与知识生命周期 |
| 规则 | Hooks 规范 | Runtime 强制执行集成 |

| 工作台 | DSH preset 文档 | 当前运行环境可用性 |
| Runtime | 未在已读文件中发现 package.json | 需新增或确认其他实现 |

注意：仓库 README 声明的台阶完成状态不等于已执行验证；本轮未运行任何代码或 CI。未对仓库全部文件做穷尽审计。

## 4. 既有资产保留与迁移
- **原样保留** `docs/playbook.md`、`docs/adoption.md`、`artifacts/*.template`、`examples/`，作为方法论与样例。
- **适配集成** `agents/skills/`、`agents/hooks/`、`evals/`、`infra/bands.yaml`；避免绕过现有门禁。
- **新增模块** `apps/web`、`apps/api`、`apps/worker`、`packages/{agent-core,context-engine,tool-kit,evaluator,memory,database,shared}`。
- **命名约定** 对外产品名 Agentic DevOS；仓库名暂保留 ai-native-sdlc，避免破坏已有链接。
- **规范一致性** 现有文档用 `AGENT.md`；跨工具接入时建议统一采用 `AGENTS.md` 并提供兼容映射，须审查既有引用后调整。
