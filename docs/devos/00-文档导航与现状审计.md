# Agentic DevOS · 当前实现与功能边界

核对日期：2026-11-05｜代码基线：`acb54b1`。本页替代 2026-10-30 的初始现状快照；历史过程见 [实施日志](07-implementation-progress.md)。

## 定位与当前技术栈

仓库同时包含可复用的 AI-Native SDLC 方法论和 Agentic DevOS 单机原型。当前使用 npm workspaces、Node 24 原生 SQLite/HTTP、JavaScript 核心、React 19 + TypeScript + Vite 8 管理台；没有独立 Worker 服务、PostgreSQL、Redis 或 Next.js 应用。

## 功能证据

| 能力 | 当前实现 | 来源及边界 |
|---|---|---|
| 任务与审批 | intent/spec/plan、哈希绑定审批、乐观版本、上游修改使下游失效 | `packages/agent-core/index.js`；actor 由可信调用者提供 |
| 执行循环 | 执行→验证→有限修复；取消、deadline、pending/finished 检查点 | `packages/agent-core/loop.js`；不自动调度重启后的任务 |
| 并发与恢复 | SQLite 独占租约/fencing、Worktree 生命周期、人工 resolvePending | `leases.js`、`worktrees.js`；单数据库/单主机边界 |
| 文件与命令 | 受限路径、凭据扫描、命令元数据、DockerSandbox | `packages/tool-kit/`；不是防恶意多租户 VM |
| 模型与预算 | OpenAI/DeepSeek Responses、四类工具、累计 Token/费用/轮数/工具数 | `openai-runtime.js`、`providers.js`、`model-budget.js`；真实模型 E2E 未验收 |
| 审计与报告 | SQLite 工具事件、不可变历史报告快照、输出哈希 | `evidence.js`；不是防宿主篡改审计服务 |
| CLI | create/artifact/approve/status/report/resolve/run | `cli.js`；审批身份来自 OS 用户/UID |
| 网页/API | 固定项目、任务编辑审批、运行取消恢复、事件与报告 | `apps/`；Mock 样例，不修改所选业务 Git 仓库 |
| 私有部署 | 只读预检、CI 构建、systemd loopback 服务、失败回滚 | `.github/workflows/devos-*.yml`；服务器实际状态需另查 |
| 知识库 | 文档导航、代码索引、运维与维护规范 | `docs/knowledge/`；尚无自动检索/长期记忆服务 |
